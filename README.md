# Pony's OpenWF-Mods

Scripts and Metadata Patches I've made for myself and am sharing here. All of them are made for client version 42.0.11, if you're playing on a different version they may not work.

## Ultra Golden Instinct

Originally based on this [script](https://onlyg.it/OpenWF/Mods/src/branch/senpai/Gameplay/Mark%20sabotage%20caches/Scripts/Mark%20sabotage%20caches.pluto) by Sainan, I've extensively modified it to mark all valuable and important items/points of interest in all missions. As a baseline it marks everything the Orokin Eye air support would on the entire map 10 seconds after loading a mission, and many extras have been added over time. You can find what extras have been added as comments in the script.

## Entity Finder

Debug tool, prints the type, name and tag of all entities within a configurable range (vector3 so it's a sphere) around the player avatar. Made for finding entity names to add into Ultra Golden Instinct.
